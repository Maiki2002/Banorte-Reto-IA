# Carpeta del CV

Aquí va el CV en PDF. El contenido de esta carpeta **no se sube al repo**:
es información personal y el repositorio es público.

Para usar el agente con tu propio CV:

1. Copia tu PDF aquí: `cp ~/ruta/mi_cv.pdf cv/`
2. Extrae el texto: `python leer_pdf.py`
3. Eso genera `cv/cv.txt`, que es lo que lee el agente.
